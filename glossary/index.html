★ 301 Redirect

/θriː oʊ wʌn ˌriːdərˈɛkt/

Permanent redirect — tells Google and users that a page has moved. Passes most link equity.

Постоянный редирект — говорит Google и пользователям что страница переехала. Передаёт большую часть ссылочного веса.

“Add 301 redirects for all old URLs after the domain migration.”

★ ABC Framework

/ˌeɪ biː ˈsiː ˈfreɪmˌwɜːrk/

A = Anchors (incoming link text), B = Body (page content), C = Clicks (real GSC queries). Drift = mismatch between them.

A = Анкоры (текст входящих ссылок), B = Тело страницы (контент), C = Клики (реальные запросы из GSC). Дрейф = несоответствие между ними.

“Check ABC: A says ’sports bar’, B says ’sports bar’, C says ’pizza’ — that’s drift.”

★ async / defer

/ˈeɪsɪŋk/ · /dɪˈfɜːr/

HTML attributes that allow scripts to load without blocking the page. async = independent; defer = runs after HTML is parsed.

Атрибуты HTML, позволяющие скриптам загружаться без блокировки. async = независимый; defer = запускается после разбора HTML.
